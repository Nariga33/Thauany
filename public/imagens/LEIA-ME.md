# Pasta de imagens

Coloque aqui os arquivos de imagem que você já possui (por exemplo, da
Moranguinho) para usá-los no site. Depois de adicionar um arquivo, ele fica
disponível pela URL `/imagens/nome-do-arquivo.png`.

Esta pasta está vazia de propósito: por direitos autorais, o assistente não
insere ilustrações oficiais de personagens de terceiros no código — apenas
você, como proprietária dos arquivos, deve adicioná-los aqui.
